# Axiom — Operations Consulting HTML Template
Version 1.0.0 · HTML5, CSS3, vanilla ES6 JavaScript, Bootstrap 5.3.3. No dashboard.

## Start
1. Extract the archive.
2. Open this folder in VS Code.
3. Use Live Server and open index.html, or run `python -m http.server 8080` and visit http://localhost:8080.
4. Edit pages/*.html and assets/css/style.css. See documentation/guide.md.

The hosted demo and this package share the same static sources. No build tool or npm installation is needed.

## Included
Home, About, Services, Case Studies, three detailed cases, Insights, three articles, Contact, Booking, Coming Soon, 404, and a demo privacy notice. System-aware light/dark modes, persistent RTL layout, keyboard navigation, reduced-motion support, case filters, validated forms, pending indicators, lazy image skeletons, JSON-LD, sitemap, and robots.

## Before going live
Replace fictional content and example.com, contact details, dates, social URL, privacy notice and integration endpoints. Never present fictional case outcomes as real results. Configure your hosting provider to use 404.html for unknown routes.

## Verification limits
Static link, markup-structure, image, SEO and JavaScript syntax checks were run. W3C validation, screen-reader review, browser rendering in Chrome/Firefox/Safari/Edge, and Lighthouse performance measurements remain to be run. Performance and WCAG targets are design goals, not certified results.
